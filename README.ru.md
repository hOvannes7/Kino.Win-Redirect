## ✨ Что делает расширение

- Добавляет кнопку **Смотреть** на страницах фильмов и сериалов Kinopoisk (в том числе на их подстраницах: актёры, рецензии и т. д.).
  Если на странице нет родных кнопок, к которым можно «прикрепиться», в углу появится плавающая кнопка.
- Открывает страницу `kinokino.win/film/ID/` (или `/series/ID/`). Ctrl/Cmd+клик или средняя кнопка мыши открывают её в новой вкладке.
- **Иконка в панели** — нажмите на странице фильма, чтобы открыть его на Kinokino.
- **Контекстное меню** — ПКМ по ссылке на любой фильм (поиск, списки) → *Открыть на Kinokino*.
- **Настройки** — ПКМ по иконке расширения → *Параметры*: можно сменить домен сайта, не обновляя расширение, если зеркало переедет.

## 🚀 Быстрый старт

1. Откройте `chrome://extensions/`
2. Включите **режим разработчика**
3. Нажмите **«Загрузить распакованное расширение»**
4. Выберите папку проекта

## 🧩 Структура проекта

- `manifest.json` — манифест расширения (MV3)
- `scripts/content.js` — кнопка на странице Kinopoisk
- `scripts/background.js` — иконка в панели и контекстное меню
- `scripts/shared.js` — разбор ссылок, общий для всех частей
- `options/` — страница настроек (домен сайта)
- `assets/icons/` — иконки расширения (`icon16.png`, `icon32.png`, `icon48.png`, `icon128.png`)
